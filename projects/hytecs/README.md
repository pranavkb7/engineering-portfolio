## Add a HYTECS project

1. Create a folder inside `projects/hytecs/` using a clear project name, such as `event-name-av-system`.
2. Copy the [HYTECS project template](../../docs/hytecs-project-template.md) into that folder as `README.md`.
3. Fill in the brief, your responsibilities, technical setup, delivery, and results.
4. Add approved screenshots, system diagrams, and demo links where available.
5. Add a link under **Project list**, with a one-sentence description and the project status.

## What to include

| Section | Purpose |
| :--- | :--- |
| Project brief | Explain what the project needed to achieve |
| My role | Describe the work I personally handled |
| System setup | Show how video, audio, lighting, software, or hardware connect |
| Delivery | Record installation, testing, operation, and handover |
| Results | Explain what was delivered and what was learned |
